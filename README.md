# 代表点の抽出

CT と対応するセグメンテーションから、症例ごとに `x,y,z,class` の CSV を生成します。
必要なライブラリは `requirements.txt` に記載しています。

```powershell
python extract_points.py --num-points 2000 --case 1139
python extract_points.py --num-points 2000
python extract_points.py --num-points 2000 --workers 4
python extract_points.py --image-dir data/image --label-dir data/label --num-points 5000 --output-dir outputs/custom
```

既定では `data/image` があれば使用し、なければ実データのある `data/test/image` と `data/test/label` を使用します。
`--case` を省略すると全症例を処理します。症例は `--case 1139 --case 1140` のように複数指定できます。
出力先は既定で `outputs/points/<症例ID>.csv`。既存ファイルの上書きには `--overwrite` が必要です。

`--workers` で症例を並列処理するプロセス数を指定します。既定はCPU数と4の小さい方で、`--workers 1` なら逐次処理です。
`tqdm` が完了症例数・経過時間・残り時間の推定・失敗数を表示し、症例ごとのログを完了順に出力します。
各ワーカーが画像と距離マップをメモリに保持するため、大きな画像でメモリが不足する場合はワーカー数を減らしてください。
抽出結果はワーカー数や完了順に依存しません。症例の処理でエラーが起きても他の症例は継続し、失敗があれば終了コード1を返します。

## 点数と座標

- `--num-points` は症例ごとの合計点数です。`.csv` の重み（2:2:2:1:1:10:2）で整数配分します。
- 各抽出条件（骨・筋肉の2mm条件を含む）適用後の候補数が、割当点数の3倍未満のクラスを除外します。残ったクラスの重み合計で全点数を再配分し、全クラスが条件を満たすまで繰り返します。ちょうど3倍なら採用します。全クラスが除外された場合はその症例をエラーにします。
- ボクセルは重複なしで抽出します。`--seed 0` が既定で、症例単独実行でも一括実行でも同じ結果になります。
- 各候補について、全クラスの既存代表点への最短距離を `d` mm として、`min(d / 5, 1)` を抽選重みに使います。5mm未満の点も抽出されます。最初の代表点では距離重みを1とします。画像のaffineによる実座標を使い、採用するたびに重みを更新します。
- 脂肪では「境界距離の二乗 × 代表点への距離重み」、他のクラスでは代表点への距離重みで抽選します。CSVのクラス順で抽出し、採用済みの点は重み0となるため重複しません。
- 距離重みが1になる距離は `--distance-scale-mm 5` で変更できます。旧オプション `--min-distance-mm` も同じ意味の別名として使用できますが、最小距離の制約ではありません。

距離重みマップを全クラスで共有し、新しい点から半径5mm未満のボクセルだけを
`min(現在の距離重み, 新しい点への距離 / 5)` に更新します。5mm以上では重みは変わりません。
現在のクラスの累積重みをセグメント木で保持し、乱数1個による逆累積分布法で毎回1点を確定します。
棄却・再抽選はありません。抽選自体は確率的ですが、同じseed・入力・設定なら再現できます。
次のクラスの木は共有マップから構築するため、先に抽出した他クラスの点も反映します。
候補数をM、1点の更新範囲内のボクセル数をBとすると、木の構築はO(M)、
1点の抽出と局所更新はO(log M + B log M)。共有マップと木の分のメモリが必要です。
- 既定の座標は NIfTI 配列の0始まりのインデックス `x,y,z` です。`--coordinates world` で画像の affine による RAS+ 実座標を出力します。
- 距離計算はヘッダーのボクセル間隔を使用します。空間単位が未設定の入力は警告の上で mm と解釈します。CT 値は NIfTI のスケーリング適用後の値を HU として扱います。
- 画像とラベルの形状一致、隅点での位置ずれ0.1mm以内を確認します。大きく異なるグリッドは自動補間せずエラーにします。
- 方向軸の正規化内積で最大0.001までの非直交性を許容し、距離計算では直交格子と近似します。それを超えるせん断はエラーにします。

## 抽出規則

`.csv` のクラス名と重みを読み、以下の抽出方法をコードで実装しています。自然言語の説明を書き換えても閾値や処理は自動変更されません。
元CSVの閉じ忘れた引用符は許容し、元ファイルは変更しません。

| class | 抽出条件 |
|---|---|
| fat | HU -190〜-30 を6連結で分割し最大成分を保持。内部の10ボクセル以下の穴を6連結で埋める。その内部の HU -150〜-50 の候補を境界までの距離で並べ、下位半数を除外。距離の二乗を確率重みとして抽出。 |
| bone | 骨ラベルの合併領域から、背景ボクセル中心までの距離が2mm以上の点。 |
| muscle | 筋肉ラベルの合併領域から、背景ボクセル中心までの距離が2mm以上の点。 |
| lung gas | 肺葉ラベル内で HU ≤ -900。 |
| digestive gas | 消化管ラベル内で HU ≤ -900。 |
| digestive system | 消化管ラベル内で HU ≥ -500。 |
| unknown_anatomical | 非ゼロラベル領域のうち、上記の抽出候補領域のいずれにも属さない点。 |

脂肪の距離はボクセル単位のユークリッド距離です。距離同値の場合も下位 `floor(N/2)` 個を除外します。
骨・筋肉の距離は物理間隔を反映したユークリッド距離です。画像外は背景とします。
候補領域が重なる場合は上表の順に優先し、点の重複を防ぎます。

ラベルIDは `ttsg_label_definition.label` の名前から解決します。
骨には仙骨・椎骨・肋骨・上腕骨・肩甲骨・鎖骨・大腿骨・寛骨・頭蓋骨・胸骨を含め、肋軟骨（`costal_cartilages`、ID 117）は含めません。筋肉には殿筋群・背部深筋・腸腰筋を含めます。
「消化器」は胃・小腸・十二指腸・結腸と解釈し、食道（`esophagus`、ID 15）・肝臓・胆嚢・膵臓は含めません。
食道・肋軟骨も非ゼロラベルとして残るため、ほかの抽出条件に該当しない部分は `unknown_anatomical` の候補になります。
`class` 列は上表のクラス名文字列です。

## 代表点のラベル画像と可視化

```powershell
python visualize_points.py
python visualize_points.py --case 1139 --preview --skip-existing
python visualize_points.py --input-dir outputs/custom --output-dir data/points_custom
```

既定では `outputs/points/*.csv` を元画像と同じ形状・座標系の `data/points/<症例ID>.nii.gz` に変換します。
代表点のボクセルだけをラベル化し、それ以外は0です。点を球に膨張させません。
`.csv` の上から順に1: fat、2: bone、3: muscle、4: lung gas、5: digestive gas、6: digestive system、7: unknown_anatomical。
症例内で抽出されなかったクラスがあっても番号は詰めません。対応表は `class_mapping.json` に保存します。
元CTとラベル画像は3D Slicerなどで重ねて表示できます。
`--preview` で全点をクラス別に色分けした3D散布図PNGも同じ場所に保存します。
実座標CSVを変換する場合は `--coordinates world` を指定してください。範囲外・未知クラス・同一ボクセルへの重複はエラーにします。
既存結果は `--skip-existing` でスキップ、`--overwrite` で再生成できます。
